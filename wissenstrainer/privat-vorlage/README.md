# Wissenstrainer – private Ablage

Dieses Repository ist **privat**. Nur du siehst die Dokumente und die Karten.

- Dokumente kommen in `privat/<Paketname>/`, z. B. `privat/Schuldenbremse/paper.pdf`.
- Nach ein bis drei Minuten liegen die Karten in `karten/<paketname>.json`.
- Die App zeigt diese Pakete an, sobald sie unter **Mehr → Mit Schlüssel verbinden** mit
  einem Schlüssel verbunden ist, der Zugriff auf dieses Repository hat.

Einmalig nötig: unter **Settings → Secrets and variables → Actions** ein Secret
`ANTHROPIC_API_KEY` mit deinem Claude-API-Schlüssel anlegen.

Die ausführliche Anleitung steht im öffentlichen Projekt:
<https://github.com/tilopatzolt/lehrreich/tree/main/wissenstrainer>
